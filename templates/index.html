Weighted Least Squares

Method Discussion

Weighted Least Squares (WLS) is a statistical and numerical method used to determine the best-fit linear equation when different data points have different levels of importance or reliability. Unlike Ordinary Least Squares, which treats all observations equally, Weighted Least Squares assigns a specific weight to each data point.

Observations with larger weights contribute more significantly to the final regression line, while observations with smaller weights have less influence. This method is particularly useful when the data contains unequal variances, measurement errors, or varying confidence levels among observations.

The general Weighted Least Squares model is:

\[ y = a + bx \]

Where:

  • \(a\) = intercept
  • \(b\) = slope
  • \(x\) = independent variable
  • \(y\) = dependent variable

Slope Formula

\[ b = \frac{ (\Sigma w)(\Sigma wxy) - (\Sigma wx)(\Sigma wy) } { (\Sigma w)(\Sigma wx^2) - (\Sigma wx)^2 } \]

Intercept Formula

\[ a = \frac{ \Sigma wy - b(\Sigma wx) } { \Sigma w } \]

Applications

  • Engineering measurements
  • Machine learning
  • Economics and forecasting
  • Physics experiments
