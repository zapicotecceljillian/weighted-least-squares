Worked Examples

Example 1

Given:

\[ x = [1,2,3,4] \]

\[ y = [2,5,7,10] \]

\[ w = [1,2,1,3] \]

x y w wx wy wxy wx²
1 2 1 1 2 2 1
2 5 2 4 10 20 8
3 7 1 3 7 21 9
4 10 3 12 30 120 48

Compute the Summations

\[ \Sigma w = 1+2+1+3 = 7 \] \[ \Sigma wx = 1+4+3+12 = 20 \] \[ \Sigma wy = 2+10+7+30 = 49 \] \[ \Sigma wxy = 2+20+21+120 = 163 \] \[ \Sigma wx^2 = 1+8+9+48 = 66 \]

Compute the Slope

\[ b = \frac{ (\Sigma w)(\Sigma wxy) - (\Sigma wx)(\Sigma wy) } { (\Sigma w)(\Sigma wx^2) - (\Sigma wx)^2 } \] \[ b = \frac{ (7)(163) - (20)(49) } { (7)(66) - (20)^2 } \] \[ b = \frac{ 1141 - 980 } { 462 - 400 } \] \[ b = \frac{ 161 }{ 62 } = 2.59677 \]

Compute the Intercept

\[ a = \frac{ \Sigma wy - b(\Sigma wx) } { \Sigma w } \] \[ a = \frac{ 49 - (2.59677)(20) } { 7 } \] \[ a = \frac{ 49 - 51.93615 } { 7 } \] \[ a = -0.41935 \]

Final Equation

\[ y = -0.41935 + 2.59677x \]

Example 2

Given:

\[ x = [2,4,6,8] \]

\[ y = [5,8,12,15] \]

\[ w = [1,3,2,4] \]

x y w wx wy wxy wx²
2 5 1 2 5 10 4
4 8 3 12 24 96 48
6 12 2 12 24 144 72
8 15 4 32 60 480 256

Compute the Summations

\[ \Sigma w = 1+3+2+4 = 10 \] \[ \Sigma wx = 2+12+12+32 = 58 \] \[ \Sigma wy = 5+24+24+60 = 113 \] \[ \Sigma wxy = 10+96+144+480 = 730 \] \[ \Sigma wx^2 = 4+48+72+256 = 380 \]

Compute the Slope

\[ b = \frac{ (10)(730) - (58)(113) } { (10)(380) - (58)^2 } \] \[ b = \frac{ 7300 - 6554 } { 3800 - 3364 } \] \[ b = \frac{ 746 }{ 436 } = 1.71101 \]

Compute the Intercept

\[ a = \frac{ 113 - (1.71101)(58) } { 10 } \] \[ a = \frac{ 113 - 99.23858 } { 10 } \] \[ a = 1.37615 \]

Final Equation

\[ y = 1.37615 + 1.71101x \]
